# Contributing

## Workflow

1. Create a focused feature branch.
2. Keep domain logic independent of UI code.
3. Add tests for deterministic calculations and scoring behavior.
4. Update methodology documentation when analytical behavior changes.
5. Preserve feature/model versioning when changing outputs.
6. Open a pull request with a concise rationale and test evidence.

## Finance-model rule

Do not introduce a metric without documenting its definition, formula, source requirements, directionality, applicability, and missing-data behavior.
